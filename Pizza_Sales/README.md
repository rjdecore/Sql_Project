# Pizza Sales Analysis — SQL

## Business Objective
Analyze pizza orders to understand revenue, ordering patterns, product demand, category performance, and time-of-day behavior.

## Core Analysis
The project answers business questions around:
- Total orders and revenue
- Highest-priced pizzas
- Popular pizza sizes
- Top pizza types by quantity and revenue
- Category performance
- Orders by hour
- Average pizzas per order
- Revenue contribution by pizza type
- Cumulative revenue over time
- Top products within each category

## SQL Techniques
- Joins
- Aggregations
- GROUP BY
- Date/time functions
- Window functions
- CTEs
- Ranking
- Percentage contribution

## Tech Stack
**MySQL | SQL | Joins | CTEs | Window Functions | Sales Analytics**

## Findings & Business Value
The query set is designed to surface top-selling pizza types, popular sizes, category contribution, hourly ordering patterns and cumulative revenue. Record exact leaders and totals from the executed SQL results before presenting them as findings.

Restaurant managers can use these patterns for menu-mix review, inventory preparation and staffing around busier periods.
