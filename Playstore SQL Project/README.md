# Google Play Store Analytics — SQL

## Business Objective
Analyze mobile applications to understand category performance, ratings, installs, pricing, revenue potential, and app quality.

## Business Questions
- Which free-app categories have the highest average ratings?
- Which paid categories generate the most revenue?
- What is the free-vs-paid recommendation by category?
- How are ratings related to review volume?
- Which apps underperform relative to their category?
- How can multi-genre fields be normalized?
- How can price changes be monitored and audited?

## Advanced Database Work
The project goes beyond SELECT queries and includes:
- Triggers for price-change logging
- Stored procedures for category-level performance checks
- Functions for cleaning multi-genre fields
- Correlation analysis
- Query execution/performance concepts

## Tech Stack
**SQL | Aggregations | Procedures | Functions | Triggers | Data Cleaning | Performance Analysis**
