# SQL Analytics Portfolio

A completed collection of SQL case studies covering sales, retail, e-commerce, customer performance, media analytics and operational questions. Each featured case study connects business questions to SQL solutions, analytical findings and practical business use.

**Core stack:** SQL · MySQL · PostgreSQL · MySQL Workbench · Data Analysis

## Analytical workflow

1. Translate the business objective into clear, answerable questions.
2. Inspect schema, data types, nulls, duplicates and key uniqueness.
3. Prepare and transform data with explicit assumptions.
4. Solve the questions with readable, structured SQL.
5. Interpret the outputs in business language and identify actionable patterns.
6. Connect findings to recommendations, while distinguishing descriptive evidence from causal claims.

## Skills represented

- Joins, aggregations, CTEs and subqueries
- Window functions and ranking
- Conditional aggregation and CASE expressions
- Date/time and string analysis
- Data cleaning and transformation
- Query readability and performance investigation

Each project README documents its objective, SQL dialect, solution files, analytical interpretation and business relevance.
