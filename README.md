# SQL Analytics Portfolio

## Repository Objective
A collection of hands-on SQL projects focused on solving business and analytical problems through database design, data cleaning, querying, and advanced analysis.

## Project Areas
The repository includes projects covering:
- Sales and e-commerce analytics
- Customer and user performance
- Media/content analytics
- Retail and product analysis
- Investment analytics
- Inventory analysis
- Operational case studies

## SQL Skills Demonstrated
- Data cleaning and transformation
- Joins and aggregations
- CTEs and subqueries
- Window functions and ranking
- Date/time analysis
- Conditional aggregation
- Stored procedures and functions
- Query optimization and execution-plan concepts

Each project folder contains its own README and supporting SQL/data files.

## Primary Tooling
**SQL | MySQL | PostgreSQL | MySQL Workbench | Data Analysis**
