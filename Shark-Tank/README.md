# Shark Tank India — Investment Analytics with SQL

## Business Objective
Analyze Shark Tank India investment activity to understand funding trends, founder diversity, investor behavior, deal conversion, and portfolio diversification.

## Data Workflow
Raw Shark Tank data is cleaned with Python/Pandas and then loaded into MySQL for analytical SQL.

Preparation includes standardizing column names, handling missing values, converting investment/revenue fields, and normalizing offer flags.

## Business Questions
- Which industries receive the highest funding by season?
- Which industries have high female-to-male pitcher ratios?
- What percentage of pitches receive offers and convert to deals?
- Which seasons and industries show stronger sales/funding performance?
- Which industries show consistent funding growth?
- Which shark invests the most per deal?
- Which shark has the most diversified portfolio?

## Advanced SQL
The project includes:
- Aggregations and conditional analysis
- Window functions
- Stored procedures
- Investment/ROI calculations
- Funnel analysis
- Indexing and query-performance concepts

## Tech Stack
**Python/Pandas | MySQL | SQL | CTEs | Window Functions | Stored Procedures | Business Analytics**
