# Automotive Industry Trends — SQL

## Business Objective
Analyze used-car data to understand selling prices, mileage, ownership, fuel type, transmission, and year-over-year pricing patterns.

## Dataset
The `car_info` table includes model, manufacturing year, selling price, kilometers driven, fuel, seller type, transmission, owner, mileage, and seats.

## Business Questions
- What is average selling price by fuel type?
- Which models have the highest mileage?
- Which cars are priced unusually far from the average?
- Which cars have above-average price but below-average mileage?
- How do prices change over time?
- Which car has the highest mileage for each transmission type?
- Which models rank highest by year?

## Advanced SQL
The project includes:
- CTEs
- Window functions
- Running/cumulative calculations
- Moving-average style analysis
- Year-over-year comparisons
- Ranking and outlier-style filtering

## Tech Stack
**SQL | CTEs | Window Functions | Time-Series Analysis | Ranking | Automotive Analytics**

## Findings & Business Value
The queries compare average selling price by fuel type, model mileage, listings above/below average, price trends and rankings by transmission/year. Quote specific models and values only from executed query results; the data describes the supplied used-car dataset.

## Business Value
This analysis can help compare used-car listings, explore price/mileage trade-offs and identify records for further inspection.
